# Crafted Totems

**Craft Totems of Undying and give yourself another chance at survival.**

Crafted Totems is a simple Minecraft mod that adds a crafting recipe for the **Totem of Undying**, giving players an alternative way to obtain totems without having to hunt down Evokers.

## ✨ Features

* 🟡 Adds a craftable **Totem of Undying**
* ⚒️ Uses a custom crafting recipe
* 🎯 Keeps the recipe balanced around the value of the Totem
* 🧩 Lightweight with no unnecessary features
* 🌱 Designed to fit naturally into vanilla Minecraft

## 📦 Installation

1. Install the required mod loader for your Minecraft version.
2. Download the latest version of **Crafted Totems**, You can get it here ['Crafted Totems'](https://modrinth.com/mod/crafted-totems)
3. Place the `.jar` file into your Minecraft `mods` folder.
4. Launch Minecraft and start crafting!

## 📖 Why?

Totems of Undying can normally only be obtained by defeating **Evokers**. Crafted Totems provides another option for players who want to obtain them through crafting and resource gathering.

## 🧱 Compatibility

Crafted Totems is designed to be lightweight and should work alongside other mods without changing vanilla gameplay beyond the added crafting recipe.
